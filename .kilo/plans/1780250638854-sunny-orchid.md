# Plan: Apply Open Design Styles to Brand & Cigar Pages

## Objective
Replace the existing Tailwind/DaisyUI-based styles in three templates with the **Open Design luxury theme** (`mc-luxury-theme.css`) classes. The `price_tracker` app and `base.html` are already styled and must not be touched.

## Prerequisites (Confirmed)
- `static/css/mc-luxury-theme.css` exists and is linked in `base.html`
- `base.html` already has the Open Design topbar, mobile nav, fonts, and CSS variables
- All three templates extend `base.html`

## Templates to Modify

### 1. `templates/cigars/brand_list.html` (Brand Directory)
**Source design:** `.opendesign/brands.html`

#### Structure Changes
- Replace `container mx-auto px-4 py-8 max-w-6xl` → `container`
- Add `page-header` section with `page-title` (h1 + subtitle) and `page-actions` (search box)
- Replace section header → `category-section` with `category-header` (`category-title` + `category-count`)
- Replace grid → `brand-grid`
- Replace card → `brand-card` with `brand-logo`, `brand-name`, `brand-count`, `brand-tags`
- Replace badges → `tag`, `tag-accent` (古巴), `tag-gold` (全球品牌)
- Add `empty-state` element for search-no-results
- Add client-side search JS (`brandSearch` input filtering `.brand-card` visibility)

#### Data Mapping (preserve existing Django tags)
- `{{ total_brands }}` → subtitle count
- `{{ section.label }}` → split into `category-title` and `category-count` (extract count)
- `{{ brand.logo.url }}` → `brand-logo img` with onerror fallback to initial letter
- `{{ brand.name }}` → `brand-name`
- `{{ brand.cigar_count }}` → `brand-count`
- `brand.origin`, `brand.category` → `tag-accent`, `tag-gold`, default `tag`
- Discontinued brands: apply `opacity-50 grayscale` (or theme equivalent muted style)

### 2. `templates/cigars/brand_detail.html` (Brand Detail)
**Source design:** `.opendesign/brand-detail.html`

#### Structure Changes
- Replace breadcrumb → `breadcrumb container`
- Replace brand header → `brand-hero` with `brand-hero-logo`, `brand-hero-info`, `brand-hero-stats`
- Add `toolbar` with `search-box` and `filter-group` (`filter-pills`: 全部/常规/限量/地区限定)
- Replace cigar list → `cigar-list` + `cigar-row`
- Each row: `cigar-row-img`, `cigar-row-info` (name/en/spec), `cigar-row-badge` (hot/limited), `cigar-row-price`
- Add `empty-state` for no search/filter results
- Add client-side JS for search + filter pills

#### Data Mapping
- `{{ brand.logo.url }}` → `brand-hero-logo img`
- `{{ brand.name }}` → `h1`
- `{{ brand.english_name }}` → `brand-hero-en`
- Brand meta (origin, category) → `brand-hero-meta` spans
- `{{ total }}` → stat "款雪茄"
- Section cigars → `cigar-row` elements:
  - `cigar.primary_image.thumbnail.url` → `cigar-row-img img`
  - `cigar.name` → `cigar-row-name`
  - `cigar.english_name` → `cigar-row-name-en`
  - Size/vitola/release_type → `cigar-row-spec`
  - Price → `cigar-row-price` (if available, else hide)
  - `cigar.release_type` → badge mapping: EL/ED → "限量" (limited), RE → "地区", else "HOT"
- Filter `data-type`: map `release_type` to `regular`/`limited`/`regional` for JS filtering
- Keep child-count badge logic ("+N" span)

#### Important Notes
- The demo has SVG placeholder cigar images; use actual `img.thumbnail.url` from the model
- The demo includes a "均价" stat that may not exist in context — omit or hide if no data
- Preserve the "停产" alert banner but style it with theme colors

- Replace breadcrumb → `breadcrumb container`
- Replace hero grid → `detail-hero` with `detail-image-wrap` + `detail-info`

#### Data Mapping

#### Important Notes
