# Django → React 全面迁移计划

## 目标
将所有 Django 模板渲染的页面迁移为 React SPA 前端渲染，保持现有视觉设计不变，取缔所有 DaisyUI 组件，使用纯 Tailwind CSS + 自定义组件实现。

- 修改 Django `urls.py`：

  - 保留 `/privnote/create/`（API）、`/p/<token>/`（如果保持 Django）

## 技术风险与注意事项

1. **Django CSRF**：React SPA 需要正确携带 CSRF token。当前 `api.ts` 已从 cookie 读取，继续沿用。

2. **Django Session 认证**：登录后通过 `Set-Cookie` 设置 sessionid，后续 API 请求自动携带。需要确保 CORS 和 cookie 设置正确。

3. **图片路径**：雪茄图片使用 Django `MEDIA_URL`，React 中需要拼接绝对路径（如 `/media/cigars/...`）。

4. **SEO**：本项目为内部工具，SEO 不是重点。如需 SEO 可考虑 Next.js，但会增加复杂度。

5. **Django Admin**：保留 `/admin/`，不受影响。

6. **Tailwind CSS v3 vs v4**：当前使用 v3，保持 v3 不升级，避免 Breaking Change。

7. **路径冲突**：现有 `/cigar/<id>/` 是目录详情，React 已有 `/cigar/:id` 是价格监控详情。迁移后统一 SPA 中需要区分：
   - `/cigar/:id` → 雪茄目录详情（从 Django 模板迁移）
   - `/prices/cigar/:id` → 价格监控详情（已有 React 页面）
