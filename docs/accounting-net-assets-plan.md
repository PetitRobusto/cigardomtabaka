# 账务工作台净资产快照

用户确认将工作台第一张卡从“总资产”改为“净资产”。预售收款增加资金及履约负债，不应使净资产或经营利润增长。

## 口径与边界

- 保留 `total_funds_cny` 原公式：全部已入账资金账户人民币账面成本（含停用账户）＋现有库存成本＋已付款在途采购＋带符号的会计应收。
- 新增 `customer_prepayments_cny`、`dividend_payable_cny`、`net_assets_cny`。前两项为同一业务日已入账科目余额取反，净资产＝原资产统计－客户预收－待付分红，Decimal 保留两位小数。
- 不截断负值，不根据订单收款状态推算负债。未初始化时以上字段均为 null。
- 退货后，出库前收款恢复为预收科目，出库后收款可能表现为负应收。原资产统计已包含负应收，不再另扣“待退款总额”，本次不增加容易误解的负债合计字段。
- 前端替换现有卡片的标题、数值及公式提示，不新增布局。正式账务流水、库存、订单和数据库结构均不修改。

## 验证与交付

覆盖分次预收、换汇、采购付款、到货自动预留、出库利润、尾款、退货待退款、实际退款、取消待退款、分红分配及领取；重复动作及失败不能改变快照。覆盖停用账户、业务日过滤、未初始化的 null 值、负净资产和前端卡片。

本地目标测试、类型检查与构建后独立审查；沿用用户合并部署授权，生产只部署 CI 通过的准确提交，随后只读核验。
