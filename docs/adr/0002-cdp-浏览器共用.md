# 0002 — CDP 浏览器共用替代各自启动

**状态：** 已采纳  
**日期：** 2026-06-06  
**决策者：** 板儿面

---

## 背景

价格爬虫最初每个源独立 `chromium.launch()`。3 个 Playwright 爬虫同时跑时，内存飙到 3G+，cron 250s 超时频繁触发。需要降低资源开销。

## 选项

| 方案 | 描述 | 优点 | 缺点 |
|------|------|------|------|
| A: 各自启动 | 保持原状 | 隔离性好 | 内存爆炸，启动慢 |
| B: CDP 共用 | Chrome 常驻 9222，爬虫 `connect_over_cdp()` | 内存省 ~1G | 共享状态，browser 崩了全挂 |
| C: 串行化 | 一个接一个跑 | 不会超内存 | 总时长 ×3 |

## 决策

**选 B：CDP 浏览器共用。**

- Chrome 以 `--remote-debugging-port=9222` 常驻运行
- COH、Brussels、DL 三个爬虫用 `chromium.connect_over_cdp('http://127.0.0.1:9222')`
- 各自创建独立 context，不共享 cookie/session
- **禁止 `browser.close()`** — CDP 浏览器是共享的，关闭影响其他爬虫

## 后果

**好处：**
- 内存从 3G+ 降到 ~1.9G
- 爬虫启动不再需要 launch Chromium（省 3-5s/源）
- 3 个源并行跑总时长 ~210s，cron 250s 足够

**代价：**
- CDP Chrome 必须常驻，挂了所有爬虫一起挂
- 长期运行指纹被 Cloudflare 拉黑（Nyon 因此独立，见 ADR-0001）
- 爬虫代码不能 `browser.close()`，只能 `context.close()` / `page.close()`

## 验证

```bash
# CDP 连通性检查
curl -s http://127.0.0.1:9222/json/version | python3 -m json.tool
```
