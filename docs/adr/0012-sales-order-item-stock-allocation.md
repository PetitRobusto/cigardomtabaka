# 0012 — Sales Order Item 与 Stock Allocation 分离

**状态：** 已采纳
**日期：** 2026-06-15
**决策者：** 板儿面

---

## 背景

同一款雪茄可能同时存在多个采购批次，成本不同且 FIFO 顺序不同。客户购买一款雪茄时，业务上只是一行销售明细，但库存和利润计算可能需要从多个批次分配数量。

## 决策

`Sales Order Item` 表示客户视角的一行商品，不因内部成本批次不同而拆分。批次占用和消耗通过 `Stock Allocation` 记录；一条销售明细可以对应多条库存分配。

例如客户买 10 支，老批次剩 3 支、新批次有 20 支时，销售单展示一行 10 支，内部创建两条分配：老批次 3 支、新批次 7 支。

## 后果

**好处：**
- 客户单据和业务报表保持商品行语义，不暴露内部批次。
- FIFO 成本和利润可以精确到批次。
- 取消、确认付款和库存审计能追溯每一支来自哪个批次。

**代价：**
- 销售明细的成本需要从多条分配汇总，不能只靠一个 `unit_cost` 字段表达全部事实。
- 订单创建服务必须处理跨批次分配和库存不足校验。
