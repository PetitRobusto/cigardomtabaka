# 0014 — 销售单可混合现货和预售明细

**状态：** 已采纳
**日期：** 2026-06-15
**决策者：** 板儿面

---

## 背景

客户可能在同一笔交易里同时购买现货和预售商品。若强行拆成两张销售单，客户收款、沟通和订单统计会变复杂；若在订单层只标记一种类型，又无法准确表达每个商品的履约规则。

## 决策

`Sales Order` 是客户交易容器，可以同时包含现货和预售明细。`Fulfillment Type` 放在 `Sales Order Item` 层：现货明细走库存预留、批次分配和出库；预售明细不占用现货库存，走预售履约流程。

## 后果

**好处：**
- 客户视角保持一张订单和一次收款。
- 库存系统能按明细区分现货和预售，不污染 Available Stock。
- 报表可以按销售明细的履约类型拆分现货销售和预售。

**代价：**
- 订单整体状态保持简单时，部分履约或等待预售需要从明细和命令记录中判断。
- 服务层必须避免用订单状态单独推断库存动作。
