# 0021 — 销售分次收款与独立履约

状态：已采纳。日期：2026-10-21。

## 背景

客户可先付部分货款，公司用收到的资金换汇、采购。原有每单一笔整单收款的限制无法表达实际到账；收款与履约已经由现有业务命令分离。本决定取代 ADR 0015 的单状态设想，以及 ADR 0014 中“一次收款”的假设。

## 决定

销售单继续采用履约、收款两个独立状态。每笔实收为不可变 SalesReceipt，允许多笔、跨人民币账户；累计与剩余由未撤回事实计算，禁止超收。状态由累计实收决定，不改变订单总额。

出库前收款记客户预收；出库时分别结转已预收与剩余应收，出库后的收款冲减应收。幂等出库重放按账务 effective_sequence 截止重建当时预收，不包含后续尾款。跨履约历史补录暂不自动重分类，日期不一致时拒绝。

人工核实必须明确实收金额，经确认弹窗核对日期和到账账户。凭证原应收快照保留，实收取关联收款。同订单允许多条已核实凭证，但最多一条待核实；每条凭证只能入账一次。

退款保持一次退清有效实收；按原收款账户和科目汇总，整笔原子执行。SalesRefund 是退款动作总事实，多账户时 fund_account 为空，账户明细来自同一账务交易的分录；单账户和历史记录保持原有字段。暂不建客户余额、超收或分次退款模型。

## 后果

待收列表和客户付款页均以剩余金额跟进，部分到账不再关闭付款流程。撤回明确针对最新有效收款，继续遵守未出库、无后续流水或对账的门禁。迁移仅解除单笔收款/单条已核实凭证限制、扩展状态和多账户退款表示，不回填或重写历史财务事实。
