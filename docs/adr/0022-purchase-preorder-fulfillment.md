# 0022 — 采购来源预售沿用原销售单履约

**状态：** 已采纳
**日期：** 2026-10-21

## 背景

经营者需要销售尚未付款、尚未到货的采购商品，用客户预付款补足采购资金。已有销售单支持预售明细和分次收款，但缺少采购来源、数量承诺和到货后的备货动作。

## 决策

销售明细可关联来源采购单。关联采购单而非采购明细，因为采购草稿编辑会重建明细。按照商品、销售单位和盒规聚合支数，确认时锁定来源采购并检查有效确认数量不超过采购数量。草稿不占额度；取消和整单退货释放额度。来源采购不能删去已确认预售商品、改变包装或缩量至承诺以下。

采购到货事务内自动在同一销售单上按既有 FIFO 库存规则建立分配，防止到货后重复出售。到货后才确认预售的，在确认事务中立即预留。来源表达采购承诺，实际批次由库存分配记录表达，二者不强制一一对应。预售明细保持原类型，不创建替代销售单，不新增可变的备货状态字段；分配表示预留。用户选择取消手动备货环节，完整预留后直接出库；历史 `prepare_sales_preorder` 事件仍保留，但不再是出库必需条件。

出库不重复扣减已预留数量；历史尚未分配的预售在正式出库事务中补分配并记录预留事件，不虚构备货事实。收款、出库仍使用既有正式命令。来源已预留、备货或出库时禁止撤回采购到货，即便实际 FIFO 分配来自更早批次。自动预留与到货同一事务，失败全部回滚；到货重放核对不可变入库事实和后续合法库存流水，不要求库存保持未使用状态。

## 后果

客户订单号、收款和履约历史连续；采购额度与实际库存分别约束，既不超卖采购承诺，也不产生负库存。旧预售没有虚构采购来源，仍可在库存充足时直接出库。

本次不支持部分出库、跨包装转换预售额度或客户钱包。出库必须等全部来源采购到货；日期不能早于来源到货、实际批次入库、自动预留及已存在的历史备货日期。
