# 0023 — 三语公开商城采用 React 预渲染

状态：已采纳（2026-10-22，用户批准的 SEO 商城计划）

公开页面必须在首个 HTTP 响应中提供完整商品正文、卢布报价、链接和语言元数据。
现有纯 SPA 的身份加载和年龄确认分支会移除正文。修订 ADR 0006：内部工作台仍使用
React SPA；公开商城使用同一仓库的独立 React 入口，由 Node 离线预渲染，Django
只提供 JSON 和已生成 HTML，不新增 Django 产品模板，也不按 User-Agent 区分正文。

公开读模型只输出商品、可售完整盒及单支状态和明确发布的 RUB 零售价。
单支只读取有效批次的 `available_stick_quantity`，使用 `sale_unit=stick`、
`box_size=null`；没有独立单支零售价时显示询价，不拆盒、不由盒价或成本推算。原有 CNY 定价、
库存事实和会计不变。已存在的中文目录保留原地址与资料；商城上架和外语翻译须
明确发布，撤回/删除优先于旧缓存。品牌标识沿用正式映射，不运行时推导图片名称。

数据库保存语义 payload、目标版本、最近成功 HTML 和重试状态。事务提交后只登记
刷新意图，worker 合并变化、比较内容散列、调用 React renderer，并原子发布整组
变更。渲染失败保留可公开的旧页面；新页面不暴露空壳。每小时对照来源补偿遗漏，
不把每次重新构建伪装成 sitemap 的内容更新时间。

前端构建产物包含浏览器入口和自包含 Node renderer。旧哈希资源保留供缓存 HTML
使用。商城以配置开关渐进启用，启用前先验证门店资料、翻译、完整 artifact 集和
真实 404/重定向；新前端发布需重启 worker。部署仍需单独授权和准确 CI SHA。

年龄确认覆盖已存在的正文，并控制用户交互；语言由 URL 决定。未核实的地址、
营业时间、图片和资质不自动发布。Google/Yandex 搜索后台基线、站点归属和地图
资料维护需要对应账户访问，不能从代码推断收录或排名。

2026-10-23 补充：用户认可 B2 视觉后要求 SPA 站内切换，SEO 为硬门禁。保留所有
首访/直接链接的完整预渲染响应，hydration 后仅增强同源商城链接和 GET 表单；
客户端同步页面元数据并保留浏览器历史、焦点与滚动。服务端/客户端共享结构化数据生成器。
发布前对全部 1448 个页面做无 JS 语义对比，结果零差异。详细边界与验证见
[SPA 导航合同](../storefront-spa-contract.md)。

2026-10-23 补充：zh、en、ru 的目录商品集合由公开商品与库存事实决定，不由翻译覆盖率决定。
缺少目标语商品译文时，只能读取已发布英文译文；仍无英文译文时使用 `english_name` 与目录中
现有规格字段。不得读取未发布草稿或生成品牌介绍、商品营销文案。品牌正文允许为空并保持为空。
页面输出 `translation_complete`、`content_locale` 和 `indexable`；使用回退内容的页面保持可浏览，
但返回 noindex 且不进入 sitemap/hreflang。界面语言切换仍提供三语路径。发布翻译可以让页面
重新进入索引，撤回、删除及缓存依赖校验仍优先于旧 HTML。
