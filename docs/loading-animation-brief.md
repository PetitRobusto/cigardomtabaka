# CigarDomTabaka 加载体验设计任务

## 用户目标与交付

为既有 CigarDomTabaka React SPA 制作一个足够 fancy、精致且有辨识度的品牌加载动画。动画应随入口 HTML 尽早出现，动画播放期间并行下载和加载应用与当前页数据，内容就绪即可退场。用户允许新技术，但明确要求禁止 Google Fonts。网页应用，一个核心流程，精致产品界面；本文件规定视觉和行为，不再提出风格选择问题。

在既有 OpenDesign 项目 `cigardomtabaka` 开启独立 run/conversation，仅创建 `brand-loading-20260915.html` 及其专属依赖。先阅读项目 `brand-spec.md` 与已有页面，保留所有既有设计。输出可直接运行的 HTML 动画预览、完整源码和简短集成说明。不要创建新项目，不修改现有页面，不操作业务数据，不重新设计整个网站。

## 唯一视觉方向：The Humidor / 雪茄盒上的烫金印记

不是一般的转圈或三个跳点。画面中心是一枚精细的横向雪茄环标，像奶油纸上逐渐显现的酒红与古铜金压印；两缕细腻、半透明的暖灰烟丝缓慢升起，品牌名以有节奏的遮罩显现。整体有奢侈品片头的工艺感，动势克制但明确可见。严格按下述构图制作单一方向，不额外设计多个风格。

### 颜色与字体（固定）

- 背景 #FAF8F5，前景 #2C2416，辅助文字 #8A7E6E，边线 #E8E0D6。
- 酒红 #7A1F2E 用在环标中心和品牌印记；古铜金 #B87A3A 用在细线与极小高光。
- 纯白可用于细微材质光泽。禁止黑底、霓虹、蓝紫渐变、彩虹、大片金色、玻璃卡片、夸张光晕。
- 标题 Georgia, 'Songti SC', 'Noto Serif SC', serif；正文 -apple-system, 'Segoe UI', system-ui, sans-serif。这些均为本机字体回退，不下载字体。
- 绝对禁止 fonts.googleapis.com、fonts.gstatic.com、Google Fonts CSS、其他外部字体 CDN 和任何 @import 远程字体。无外部图片依赖。

### 固定构图

- 桌面与手机共用单列居中构图，背景完整覆盖视口；主视觉组位于视口中心略上（约 46% 高度），周围大面积留白。
- 主视觉约 220 × 148px，手机约 180 × 128px；透明 SVG 中心为横向雪茄环标，宽约 170px、高 55px，双层金色细边，侧翼短而有层次，中间酒红小盾形/椭圆核心内仅有衬线字母 C。这是加载专用图形，不替换产品正式 Logo。
- 线宽约 0.7–1.2px，避免廉价粗线；两条暖灰烟丝从环标上侧偏右升起至上方 60px，高度和曲线不同，透明度 0.10–0.22。
- 主视觉下方 24px 是 CigarDomTabaka 品牌名，桌面 28px、手机 24px，深褐色衬线，中等字距，禁止逐字上下跳动。
- 品牌名下方 10px 为真实状态文案，13px：默认“正在准备你的雪茄世界”。组件态可以换成“加载品牌数据…”等实际文本。
- 下方 22px 有一条 96px 长、1px 高的淡边线，其间一小段铜金光迹缓慢经过，表示未知时长加载；不显示百分比，不伪造阶段或进度。
- 不添加宣传段落、CTA、菜单、图片、时间、假服务器信息、城市标语或无关装饰。

## 精确动效编排

1. HTML 首次可绘制时必须已有背景、环标底稿与可读品牌名；任何脚本未就绪都能看到完整静态标志，不能先 opacity:0 等脚本揭幕。
2. 入场约 900ms：0–420ms 金线沿轮廓描出，180–650ms 环标中心柔和显影并从 0.97 缩放至 1，320–900ms 品牌字标有一束宽而淡的纸面光泽从左向右扫过。不要等待入场完成才发起网络请求。
3. 持续加载时：2.8–3.6s 的平滑循环中烟丝缓升并淡出，另一缕错开约 1.2s；金色光迹用 transform 平移；中心印记仅有约 1% 的极轻呼吸。避免明显跳跃、突然回到起点及全屏滤镜。
4. 内容就绪：立即开始约 220–300ms 的整组 opacity 淡出与最多 4px 向上移动，同时露出内容；禁止强制播放满一轮、人为设置最低展示时长、等待所有图片下载完成。即使 100ms 已就绪也必须可以退场。
5. 慢网络超过 10s：保留同一设计，状态文案变为“加载时间较长，请稍候”，出现低调的“重新加载”文字按钮。失败状态须显示可读错误及重试，不允许无限动画掩盖已知错误。
6. prefers-reduced-motion: reduce：静态环标与品牌文字，无烟丝漂移、描边和扫光；内容就绪立即移除，不等待 animationend/transitionend。
7. 页面内加载使用同一视觉的小型版本：主视觉 112 × 80px，容器上下 padding 48px，实际状态文案；不出现遮挡页面导航的全屏幕布。

## 技术与性能约束

- 用户不限制实现技术，可使用 SVG、CSS、Web Animations API、Canvas 等；依据效果选择。精致度来自几何与时间编排，不可为了使用某库牺牲首次显示。
- 首次可见的版本必须是自包含 HTML + 内联 CSS/SVG，不依赖 React、动画库、网络字体或网络图片加载完毕。核心压缩后目标 ≤ 8KB。
- 可选增强必须渐进加载，基础动画始终可用；本效果没有必须使用 WebGL/视频的理由。如果选择增强，请说明实际收益与体积，不引入没有使用的依赖。
- 尽量使用 transform/opacity；SVG 描边只在小图形入场时使用，禁止持续全屏 blur、feTurbulence 或几百个 DOM 粒子。没有鼠标跟随或滚动监听。
- 不接入业务 API。预览允许一个独立的“仅预览”控制面板演示：正常 2.5s、快速 0.1s、慢速 12s、失败、页面内、减少动态效果和重新播放。预览控制面板必须与生产组件清晰分离，默认打开即播放，播放完成后用简洁的品牌目录占位证明退场。
- 实际集成将覆盖 Vite index.html 和 Django 唯一 SPA 入口，React 接管后继续统一视觉；源码请保持可抽取，提供 loading/ready/error 和销毁/清理接口说明。不新增 Django 产品页面。
- 可访问性：可读状态 role=status/aria-live=polite；装饰 SVG aria-hidden；重试按钮有键盘焦点；不要让已隐藏的覆盖层阻断交互。

## 验收清单

- 在 1440×900 与 390×844 均居中且无横向溢出。
- 画面严格遵守指定环标、烟丝、品牌名和细光迹结构；fancy 来自细节与动效完成度。
- 不存在转圈主视觉、外部字体或远程图片请求。
- JS 关闭仍有可读静态内容；减少动态效果可用。
- 快速完成、持续加载、失败与页面内状态都能预览。
- 提供预览文件路径、核心动画源码位置、核心资源体积和实际采用技术；不要声称测试过未实际运行的浏览器检查。
