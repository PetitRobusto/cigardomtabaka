# 其他收入：人民币与卢布入账

日期：2026-11-02。更新：2026-11-03。状态：已实现、完成验证并更新本机测试服务器；未发布生产。分支：`feat/other-income`。

## 需求契约

公司已取得且已到账的非销售收入可登记为人民币或卢布。人民币统一核算，资金按实际币种收付。第一版仅覆盖收益确认与到账在同一业务日的存款利息、已费用化且剩余账面价值为零的旧物出售、来源明确的其他收益。原费用退款、内部转账、投入资本、借款本金、预收款不属于其他收入。有剩余账面价值的资产处置、应计未收、分期和跨日收款不在本期范围。

## 会计规则

- 每笔保存收款账户、币种快照、原币金额、人民币金额、分类、业务/到账日期、来源说明、参考凭证文本、操作人、Agent 来源和幂等键。旧物出售要求明确确认已费用化且账面价值为零。
- CNY 汇率固定为 1。RUB 必填业务日汇率及来源；方向为 `1 CNY = X RUB`，汇率最多 8 位小数，人民币金额为原币金额除以汇率，四舍五入到分。金额最多两位小数，折算结果必须大于零且不溢出。汇率和结果入账后冻结；不采用固定参考汇率或旧资金平均成本。
- 借记资金账户原币及人民币账面金额，贷记对应收益科目人民币金额。不创建人民币现金、不创建换汇。后续外币支出继承现有移动平均成本规则。
- 新增收益不改变销售收入、销售利润、销售排行和主营成本占比；分别展示存款利息、旧物出售、其他收益及净合计，加入最终管理利润、未分配利润和分红计算依据。利息不重复冲减财务费用。管理账不在本期新增法定外币期末重估。
- 原收入与冲正事实均只追加。专门的冲正命令保存原因、业务日期、操作人、Agent 来源和独立幂等键，使用原币及原人民币金额反向入账。通用冲正接口不放行其他收入。
- 有后续账户流水时拒绝直接冲正；已有覆盖原收入日期的已确认对账时拒绝冲正。RUB 不允许在已有更晚业务日流水前补录；CNY 仍遵守历史余额校验。新入账不允许改动已确认对账覆盖的日期。不改日期绕过限制。
- 重放核对完整请求、不可变事实及分录；并发同键只入账一次。账户停用后允许一致请求重放。已冲正原记录不得用原创建键再次入账。

## 交互与接口

现有费用登记区域改为“费用与其他收入”，提供“登记费用 / 登记其他收入”切换；收入表单含分类、账户、原币金额、日期、说明、凭证参考，RUB 额外展示汇率、来源及人民币折算。确认时列明账户变化、汇率和收益。费用与收入明细及小计分开，收入详情提供冲正。

新增受权限保护的 `/api/accounting/other-incomes/` GET/POST、`/<id>/` GET、`/<id>/reverse/` POST；金额、汇率采用字符串，金额由服务端计算。列表按业务月分页，原收入和当月冲正独立展示，汇总不受分页影响。

UI 预览已完成：通过当前会话 OpenDesign MCP 读取 CigarDomTabaka 既有设计和品牌规范，确认 Claude Code 运行器后，独立 run `dafcb561-7c4b-414c-aebd-fd14cbf575f3` 成功生成 `other-income-20261102.html`。React 沿用其费用/收入切换、原币与折算金额并列、确认弹窗和移动布局；跨月冲正及会计限制以业务契约为准。

未确认的收入/冲正请求在发送前按操作用户保存原内容和幂等键，刷新或关闭标签后可恢复同一笔。Web Locks 协调跨标签读写，UUID 避免不同标签产生重复键；迟到响应只清除自身待确认记录。不支持安全浏览器锁或无法持久保存时不发送收入写请求，提示检查浏览器/HTTPS。网络结果未知时固定原内容，仅允许重试。
