# 预售到货后直接出库

2026-10-21，用户明确选择取消手动备货步骤，改为「到货自动预留 → 待出库 → 确认出库」。沿用 feature branch，保留未提交工作，仅在本地验证，不修改生产数据。

- 采购到货、销售确认时的自动预留保持不变；已完整预留的预售无需备货事件即可出库，不重复扣可售库存。
- 移除页面备货按钮及动作表单，订单状态和库存页统一显示待出库；历史备货事件仍展示于时间线。旧备货 API 保留兼容，不再作为出库必需条件。
- 出库仍需来源全部到货、有效完整预留，日期不得早于来源到货、自动预留以及已存在的历史备货事件。保留未到货拒绝、库存不足回滚、权限、幂等、退款/退货、财务记账规则。
- 历史无来源或旧版本已到货但未分配的预售，在正式出库事务内补充库存分配并记录预留事件；失败整单回滚，不虚构备货事实。
- 验证：到货直接出库且不重复预留、未到货/多来源未全到货拒绝、日期顺序、重复出库、历史已备货与未分配订单、混合单缺货回滚、取消/退货守恒；前端不出现备货动作且显示待出库。实现期间及最终独立审查。

## 验证与发布准备

- 完整预留的预售直接出库，不产生新的 reserve 或 prepare 事实；历史无来源及未分配的已到货预售在出库事务补充 reserve。
- 新增实际批次采购入库、有效调增及期初库存的业务日期校验；跨日出库失败时补分配一并回滚。原有历史备货记录及其日期顺序保留。
