# SEO-14：公开商品范围与 sitemap 发布核验

日期：2026-10-26 UTC。状态：本地实现与验证完成，用户已授权上线；进入提交与 CI/CD，生产结果待验收。

## 需求与边界

用户确认公开访问只展示门店商品，不展示整个 Cigar 数据库或管理员资料。
公开商品必须同时满足 `ProductListing.published=True`、`withdrawn=False` 和
`Cigar.deleted_at IS NULL`。已发布但暂时售罄的商品保留；库存历史、图片或已发布译文
均不能单独赋予商品公开资格。没有库存历史但已明确发布的商品可以进入商品目录，
不得据此声称有现货。首页现货货架仍由真实库存决定。

三语详情、目录、品牌列表、搜索、相关推荐、导航和 sitemap 使用同一公开集合。
品牌必须有公开商品才生成页面。商品规格、介绍及图片仍引用关联 Cigar 资料，
不删除内部数据库、不改报价、库存、财务或既有商品的发布状态。
内部 `/library`、库存、采购、订单、财务及其 API 继续由员工权限保护；
客户通过专用令牌访问 Privnote 的既有流程保留。

用户另要求 CI/CD 必须刷新 sitemap，本次不修改 `AGENTS.md`。

## 实现约定

- 删除“所有未删除型号都生成公开详情页”的旧兼容规则；未发布商品的详情及 JSON 返回真实 404，旧 slug 不得绕过资格检查。
- 取消发布后即使旧 HTML、列表卡片或 sitemap XML 仍在缓存，也不能继续分发该商品；受影响聚合页在重新渲染前返回 503。
- sitemap 只包含已经成功渲染、资格有效且允许索引的规范页面；未完成目标语资料的回退页面仍为 noindex。
- sitemap 是动态生成的 XML。Deploy 使用新代码同步 `render_storefront`，校验缓存后执行 `check_storefront_sitemap`，通过后才重启 Web 并恢复 worker。
- 核验要求 sitemap 与当前可索引集合一致；缺漏、多余、重复、非规范 URL 或无效 XML 均使发布失败。不能把这一检查解释为搜索引擎必然收录。
