## 核验结论

1. [Top Cigars 的销售点目录](https://topcigars.ru/points/) 有大量已列零售商和 Habanos Lounge，并提供店名、地址、电话及部分门店网站；按当前页面全文搜索，未找到 `CigarDomTabaka`、`Дом Табака` 或 `Молодёжная`，因此没有证据表明本站在该目录中。目录里有相近通用名称（如“Сигары. Табак”），不能当成本店条目。
2. [Habanos.com 官方定位器的可见莫斯科条目](https://www.habanos.com/place/%D1%82%D0%B0%D0%B1%D0%B0%D0%BA-moscow/) 是名为“Табак”的 Habanos Point，地址为 Первомайская ул., 40/19，显示电话 `+7 (495) 603-21-35` 及 “Infifon II NA, N.V. Distribuidor Exclusivo”。地址、名称均与本站 `Москва, Молодёжная ул., д. 3, подъезд 6` 不同；不能将它与 CigarDomTabaka / Дом табака 合并。
3. [Top Cigars 自己的公司页](https://topcigars.ru/about/) 称其为 Habanos 在俄罗斯的分销商；但 Habanos.com 上述当前可见莫斯科条目显示的是不同的分销实体名称。两边信息存在待确认差异。本调研不据此确认当前分销授权或本站的供货关系；联系前应先由 Top Cigars 确认当前零售合作与资格。
4. 搜索精确店名和地址，未发现可确认属于本站的行业目录条目。网上有许多“Дом табака / Табак”同名条目，搜索结果中也出现不同城市或不同地址；仅名称相同不能认领、引用或请求更改。本站标准地址以 [`storefront/public_details.json`](../storefront/public_details.json) 为准。
