## 内容扩展原则

每一批页面都从用户查询或明确业务需要出发，确认页面意图、资料来源、目标语言、规范地址及与既有内容的关系。每个主题先确定主页面，再决定是补充既有页还是创建新页。

候选内容包括：

- 高希霸 Siglo、Línea Clásica、Maduro 和 Behike 的资料体系及具体型号差异。
- 中文常用名称与原文名称对照，常规版、地区版、限量版与不同盒规的区别。
- 基于门店真实设施说明保存和养护，不编造技术参数或现场条件。
- 中文访客到店信息更新，明确地址、地图、交通和联系方法。

品牌历史、生产工艺和型号参数优先核对 Habanos 等原始资料。竞争网站可提供选题，不能作为未经核验的事实来源。转载全文、批量改写同质文章、关键词堆砌和重复城市页不列入内容计划。

扩展语言只关联实际存在的等价页面，使用本语言完整正文。保留中文站现有 URL；需要迁移时制定旧地址映射、永久重定向和上线后检查，不同时制造多个可索引副本。

## 本地信誉与外部链接

地图与网站资料统一后，持续补充真实入口、店内和保存设施照片，更新节假日营业安排，并回应客户评价。可以给真实到店客户提供评价入口，不编造评价或以好评为条件交换利益。

如实际资格符合要求，可核对 [Habanos 门店记录](https://www.habanos.com/place/la-casa-del-habano-moscow/)和 [Top Cigars 销售点目录](https://topcigars.ru/points/)的申请或更正方式。只声明可证明的关系，不因页面展示标识便自称官方授权。

与真实合作伙伴、当地中文生活服务或相关行业网站建立有内容的介绍链接。没有真实门店的地铁站或城区不创建“分店”页面，也不为覆盖地区词虚构地址。

这些外部更新和联系属于后续具体任务；本文件不授权自动发送消息、提交申请、创建账号或购买服务。

## 商城阶段的衔接

商城另行立项时，尽量让已有品牌和型号页继续保留规范 URL。先决定目录型号、具体盒规和可售商品的关系，再设计商品页、变体、筛选、分页和下架行为。

需要单独确定的内容包括：

- 哪些价格、币种和库存状态可以公开，其来源和更新频率是什么。
- 目录资料页与实际交易页如何对应，如何区分历史资料、暂无可售和永久停产。
- 无货页面、旧链接和筛选参数如何处理，避免产生大量重复或空结果页面。
- 公开页面缓存、预渲染与实时商业数据如何协调，防止过期价格或错误库存承诺。
- 各搜索平台对烟草商品展示和交易相关功能的实际适用规则；不能预设 Google Product 富结果、购物 Feed 或广告可用。[Google Product 内容规则](https://developers.google.com/search/docs/appearance/structured-data/product-snippet)。

商城 SEO 不能改变 [CONTEXT.md](../CONTEXT.md) 定义的价格、库存和订单事实。目录展示不创建订单、不预留库存；正式业务操作仍通过命令或 API，财务与库存不变量另行验证。

## 后续排序方式

| 第一阶段观察 | 下一步 |
| --- | --- |
| 机器人未读到正文或有大量响应错误 | 优先修复渲染、路由和资源访问 |
| 重点页被排除为重复或低价值 | 核对规范 URL、实际正文及页面意图，不直接批量扩页 |
| 页面有曝光但点击不足 | 检查标题、摘要、语言及查询是否匹配 |
| 页面有访问但少有联系 | 检查门店资料、可信依据、移动体验和联系路径 |
| 地图曝光少 | 检查卡片关联、类别、位置和资料完整性，再看真实附近竞争 |
| 某品牌或语言已有持续需求 | 优先深化该组内容和相关型号 |
| 频繁更新让预渲染失效或维护成本过高 | 测量问题，再评估增量更新或 SSR |

每次只选择有证据支持的一批工作，写清范围和验收后再启动。整体页面数量、评价数量和单次排名均不单独作为业务成功标准。
