# 业务引导与站内使用手册设计

- 日期：2026-08-13
- 状态：已确认
- 适用对象：已登录内部操作员

## 目标

操作员首次进入系统、管理员发布新版引导或单独重置用户后，系统自动展示简短业务引导。站内同时提供可随时访问的中文使用手册，并能从手册重新播放对应页面引导。

## 状态模型

-  是单例全局配置，保存当前整数版本和是否自动展示。
-  按用户保存已完成版本、是否下次强制展示和完成时间。
- 需要展示的条件为：全局启用，且用户已完成版本低于当前版本，或用户被强制重置。
- 完成、跳过和关闭均完成当前版本；用户仍可从手册手动重播，手动重播不修改完成状态。
- Django Admin 只允许修改全局版本/启用状态和重置单个用户，不编辑引导或手册正文。

## 页面与交互

- 首次引导共六步：业务全景、库存与采购、销售单、出库与收款、账务与对账、月利润。
- 欢迎阶段使用全屏遮罩卡片；完成后进入销售页，并高亮当前页面关键区域。
- 引导支持上一步、下一步、跳过和关闭，键盘 Escape 可关闭。
-  是 React SPA 站内手册。桌面为章节侧栏加正文，手机为章节选择器。
- 手册分为快速开始和功能参考。章节提供“打开对应功能”和“播放本页引导”。
- 入口加入桌面导航和手机“更多”菜单。公开 、登录页及未登录用户不显示引导。

## 内容边界

手册正文和步骤定义随前端代码版本管理，统一中文。第一版不提供富文本、搜索、视频、分析统计或多语言。

## API

- ：返回当前版本、是否自动展示、是否需要展示。
- ：完成或跳过当前版本，幂等。
- ：仅将当前用户设为下次强制展示，供跨设备重播。

三个端点仅允许已登录 staff。登录用户 API 同时返回引导摘要，避免页面加载后闪烁。
